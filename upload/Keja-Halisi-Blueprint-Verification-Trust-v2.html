Core product rule set

  • Hakuna Kulipa Kabla Ya Kuona Nyumba
  • Viewing fee before viewing → report / review
  • 3 reports → listing auto-hidden or flagged for review
  • Listings expire automatically after configured window
  • Phone masked until user chooses Call / WhatsApp
  • Exact ID, document images and exact house numbers stay private

Caretaker flow

Availability operations

Caregiver / caretaker role gets narrow permissions: confirm occupied/vacant units, update viewing windows, respond to leads and escalate reports. No access to private verification documents.

Principle: minimum privilege by role, not one shared “agent” permission.

Privacy controls

Protect the person behind the listing

  • Public location = estate / road context, not exact house number
  • Phone = masked until user selects contact action
  • ID and selfie = private verification bucket
  • Private evidence encrypted and access-controlled
  • Lead logs contain minimum necessary contact data
  • Consent captured for verification and communications where required

Supabase policy sketch
-- public reads only approved listing fields
create policy "public read verified listings"
on listings for select
using (status = 'Available' and publish_state = 'approved');

-- poster can edit only their own listings
create policy "poster updates own"
on listings for update
using (auth.uid() = poster_id);

-- reports can be inserted, but evidence remains private
create policy "insert report"
on reports for insert with check (auth.uid() is not null);

-- verification docs are private storage objects
-- admin review goes through privileged server-side action

-- scheduled expiry
-- update listings set status='Expired'
-- where expires_at < now() and status='Available';

Recommended build order

Keep the launch sequence narrow: prove search + trust first, then expand operational depth.

1Marketplace foundation

Landing, sub-county filters, estate pages, listing detail, saved, Call / WhatsApp.

2Verification

OTP, ID/selfie workflow, role selection, admin review, verification badges.

3Trust operations

Reports, no-viewing-fee rule, duplicate checks, price anomalies, expiry cron.

4Owner / developer

Project inventory, unit catalogue, caretaker permissions, lead analytics.

5Payments

Only after core trust loop works: M-Pesa subscription / premium supply tools.

6Maps + market analytics

Live GIS, route context, sub-county market pulse and price trend reporting.

7AI moderation

Duplicate / repost similarity, bait-price alerts and moderation assistance.

8Scale

Observability, rate limiting, audit trails, data retention and disaster recovery.
